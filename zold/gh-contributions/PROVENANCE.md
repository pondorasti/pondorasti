# Hunk archive provenance

This directory is a static archive reconstructed from the four recorded Hunk
deployments for `gh-contributions`, ordered by the Hunk API creation timestamp.
Each synthetic version commit records the source deployment ID, immutable
preview URL, Hunk content hash, and exact API timestamp in commit trailers.

- Hunk ID: `197f4eff-0474-44ab-a913-6e1022c9ebe3`
- Live URL: <https://app.hunk.851.sh/domain-851-sh/gh-contributions>
- Imported versions: 1 through 4
- Latest imported deployment: `340d05e4-9fe6-41a6-9b4f-c1e01e6888f3`

The recovered deployment files are unchanged. They include the repository,
commit, pull-request, and email metadata present in the Hunk snapshots. Version
2 is intentionally represented by an empty commit because its content is
identical to version 1. `.hunk/config.json` and this document were added by the
final integration commit and were not deployment files.
