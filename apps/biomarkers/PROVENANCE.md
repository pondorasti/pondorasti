# Lab Dashboard provenance

This directory is a reconstructed archive of the public Hunk project
`lab-dashboard` (Hunk ID `b3ee78ba-6816-4c83-8c6a-e9f1fd01481c`).

The preceding 30 commits reproduce the Hunk version sequence using each
deployment's immutable preview host and displayed timestamp. Commit trailers
record the Hunk version, preview URL, and displayed time. Hunk does not expose
historical file inventories, so assets were recovered by probing the union of
paths referenced across all versions plus the current deployment inventory.

Before any files entered Git, personal street addresses and personal phone
numbers were irreversibly redacted from the PDFs. Filenames, page dimensions,
links, accepted medical content, identifiers, email addresses, and provider or
laboratory contact details were retained. The public Hunk deployment remains
online and unchanged at <https://lab-dashboard.hunk.851.sh>.
